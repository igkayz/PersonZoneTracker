# Видеоаналитика v5: Полигональные зоны + SQLite + GitHub CI/CD

## Что нового и исправленного в этой сборке
1. **Сохранены все доработки интерфейса и полигонов**:
   - Многоугольные (полигональные) зоны контроля (`default_polygon` / `factory_polygon`) с рисованием кликами мыши, автосохранением в SQLite + `localStorage` и сбросом к заводской зоне.
   - Обновленный компактный интерфейс: выпадающая кнопка справки `?`, счетчик людей в заголовке видео и сворачиваемое меню «Дополнительные опции».
2. **Исправлены ошибки запуска и работы**:
   - **`start.bat`**: убрана жесткая привязка к пустой папке `.venv`; теперь скрипт сам находит `.venv` или системный Python, доустанавливает зависимости из `requirements.txt` и запускает сервер.
   - **`yolo_person_line_detector.py`**: исправлен краш `AttributeError: 'StablePersonTracker' object has no attribute 'side_of_line'` (строка 193) при отслеживании полигона, добавлена защита от пустого полигона.
   - **`person_line_interface.html`**: возвращен элемент `#statusHintBar` (устранен JS-краш `Cannot set properties of null`) и удален лишний закрывающий тег `</div>` в шапке.
   - **`app_server.py`**: добавлена защита от пустого полигона при отрисовке OpenCV и безопасный импорт `numpy`.
3. **Готово для GitHub**:
   - Убраны мусорные папки `.venv/` и `__pycache__/`.
   - Добавлены `.gitignore`, `requirements.txt` и автопроверка + автосборка `.github/workflows/ci.yml`.

## Запуск на Windows
Просто дважды кликните по **`start.bat`** или выполните в терминале:
```powershell
pip install -r requirements.txt
python app_server.py
```
